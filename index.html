Настройка общей базы данных в реальном времени

По умолчанию уже работает мгновенная P2P-синхронизация (Gun.js) по коду комнаты. Для 100% вечного хранения подключите бесплатную Google Firebase Realtime Database:

Шаг 1. Создайте проект

Зайдите на console.firebase.google.com, нажмите Create a project (бесплатно, без привязки карт).

Шаг 2. Включите Realtime DB

В меню слева выберите Build → Realtime Database → Create Database. Выберите режим Start in test mode (открытый доступ).

Шаг 3. Вставьте ссылку

Скопируйте URL вашей базы (вида https://...firebaseio.com или ...firebasedatabase.app) в поле ниже или в константу DEFAULT_FIREBASE_URL в коде.
